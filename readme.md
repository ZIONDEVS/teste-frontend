# Teste Prático — Desenvolvimento Front-end

**Objetivo:** Desenvolver uma landing page responsiva a partir de um layout fornecido no Figma, aplicando boas práticas de desenvolvimento front-end.

**Design de referência:**
https://www.figma.com/community/file/1230604708032389430

### Tecnologias

- Obrigatório: React + Vite.
- Linguagem: JavaScript ou TypeScript (TypeScript será considerado diferencial).
- Estilização: Tailwind CSS (preferencial), CSS Modules ou outra biblioteca CSS.
- Não é necessário desenvolver backend.

### Escopo do projeto

Desenvolver as seguintes áreas do layout de referência:

1. **Header:** logotipo, navegação e menu funcional no mobile.
2. **Hero:** título, descrição, imagem/ilustração e botão de ação.
3. **Serviços:** implementar até quatro cards de serviços conforme o design.
4. **Our Working Process :** implementar até trës blocos de processo conforme o design.
5. **CTA e Footer:** seção de chamada para ação e rodapé.

### Requisitos obrigatórios

- Reproduzir o layout com fidelidade visual ao Figma.
- Desenvolver versões desktop e mobile.
- Garantir adaptação adequada em larguras intermediárias.
- Utilizar componentes React reutilizáveis quando fizer sentido.
- Implementar navegação funcional entre as seções.
- Evitar rolagem horizontal indesejada.
- Utilizar HTML semântico.
- Garantir que botões, links e menu mobile tenham comportamento adequado.
- Manter o código organizado, legível e sem erros no console.
- Incluir um README com instruções de instalação e execução.

### Diferenciais

- Utilização de TypeScript.
- Boas práticas de acessibilidade.
- Transições e microinterações discretas.
- Atenção à performance e ao carregamento das imagens.
- Organização consistente dos componentes e estilos.

### Entrega

Disponibilizar o código-fonte em um repositório GitHub e publicar uma versão funcional na Vercel ou plataforma equivalente.

O README deve explicar como executar o projeto, quais tecnologias foram utilizadas e quaisquer decisões técnicas relevantes.

**Prazo:** 2 dias úteis após o recebimento do teste.

É permitido consultar documentação e utilizar ferramentas de apoio, incluindo IA. Entretanto, todas as decisões de implementação deverão poder ser explicadas durante uma breve apresentação técnica da solução.
